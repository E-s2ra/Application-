# DENG Audio Classics — Cover Art

Twelve individually illustrated, original SVG audiobook covers for the DENG library. All artwork is built from native SVG shapes, paths, patterns, gradients, and live type. No stock imagery, third-party book covers, downloaded illustrations, raster embeds, remote fonts, or external runtime assets are used.

## Format and use

- Portrait canvas: **600 × 900 px** (2:3), with matching `viewBox="0 0 600 900"` on every file.
- Intended path: `public/covers/{slug}.svg`; referenced by the web app as `/covers/{slug}.svg`.
- Each SVG contains `title` and `desc` accessibility metadata and readable work/author type.
- Across the series, fine border framing, high-contrast primary typography, and a small vertical **DENG AUDIO CLASSICS** imprint establish a shared identity while illustrations and palettes vary.
- The visual treatments are designed to remain recognizable in compact library thumbnails. Scale images proportionally with `object-fit: cover` and a `2 / 3` aspect ratio.
- Uses common browser serif/sans-serif font fallbacks; final glyph rendering can differ slightly by device. All illustration shapes remain vector at any resolution.

The literary works are well-known classics. The cover designs here are newly constructed vector interpretations and contain no copied cover artwork. Publication rights for book text or audio recordings should be considered separately for each territory.
